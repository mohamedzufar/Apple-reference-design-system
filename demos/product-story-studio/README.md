# Reference Clone Studio — working starter

This is a self-contained, Apple-inspired product-storytelling page scaffold to adapt to a supplied reference. It is not Apple's official website and does not include proprietary Apple assets. Replace the demo copy and placeholder product art with authorized assets from the target project.

## Run
Open `index.html` directly, or serve this folder with any static HTTP server. No build step or external dependency is required.

## Included interactions
- Sticky product navigation with mobile menu
- Scroll-aware active section indicator
- Native scrolling and anchor navigation
- Feature selector that updates a content panel
- Horizontal card rail with arrow controls and keyboard support
- FAQ disclosure controls
- Reduced-motion and contrast-aware CSS
- Responsive layout and fallback styling

## Before shipping
Use the main mega skill file for reference mapping, screenshot comparison, accessibility, and browser QA. This starter is a foundation, not a verified clone of any particular screenshot.
