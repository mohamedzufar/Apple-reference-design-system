THE V1.0 SHIFT

From small updates
to complete delivery.

A design skill should not stop at a list of principles. It should inspect the existing project, preserve the reference’s section order, implement real interactions, compare screenshots, test the result, and explain what is still unverified.

01

Read the reference

Inventory the code and assets. Map every screenshot to a section, state and design decision. Label evidence instead of guessing.

02

Build the full page

Hero to footer, all middle sections, navigation, carousels, selectors, responsive states and meaningful links — not a hero-only mockup.

03

Compare and prove

Match viewport and scroll position, fix the biggest visual mismatch first, run checks and report evidence honestly.

MOTION WITH A PURPOSE

Fluid, not floaty.
Fast, not frantic.

Native scrolling stays in control. Motion clarifies state, hierarchy and continuity. Interactions remain interruptible; reduced-motion preferences are respected. No global scroll hijacking or animation for animation’s sake.

RELEASE GATES

Beautiful is a start.
Reliable is the bar.

01 / VISUAL

Matched screenshots

Same viewport, scroll position and state. Compare geometry before micro-details.

02 / INTERACTION

No dead controls

Navigation, selectors, carousel boundaries, keyboard and focus states are checked.

03 / ACCESSIBILITY

Respect user settings

Keyboard, reduced motion, contrast, zoom and narrow layouts have a planned test path.

04 / HONESTY

Evidence over claims

Separate static checks from browser tests and device performance measurements.
