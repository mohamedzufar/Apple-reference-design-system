# v0.9 Release Notes — Apple Design Intelligence & Verification

## What is new
- A full reference-to-implementation workflow with observed/inferred/unknown evidence labels.
- A product-storytelling structure with guidance against rigid, empty template sections.
- Explicit motion-engineering rules covering native scroll, interruption, pointer cancellation, reduced motion, and compositing.
- Component behavior contracts for keyboard, pointer, responsive, loading, error, and selected states.
- A visual verification loop that separates structural, typographic, and material mismatches.
- QA reporting rules that prohibit unsupported claims about FPS, Lighthouse, accessibility, and cross-browser behavior.
- Optional Playwright smoke checks and screenshot capture scripts under `tools/qa/v0.9-legacy/tooling/`.
- A reusable reduced-motion-safe motion CSS/JS reference under `tools/qa/v0.9-legacy/tooling/`.

## Validation performed on this package
- ZIP archive integrity checked after packaging.
- The existing v0.8 pages/assets were retained as the base.
- Tooling is provided as an opt-in harness and must be installed/configured before it can run.
- Browser QA of the full website is **not certified by this release note**. Run the provided checks in your own environment and review the generated screenshots.

## Compatibility
The existing static site remains usable without installing the optional Playwright tooling. The new examples are references and are not automatically injected into existing pages to avoid silently changing their behavior.
