# Light theme

- `index.html`: interactive visual reference and component gallery.
- `tokens.css`: semantic theme tokens.
- `styles.css`: responsive components and foundational styles.
- `script.js`: lightweight reveal motion and demo feedback.

Open `index.html` directly in a browser. No dependencies or build tools required.

See `MASTER-STYLE-STRUCTURE.md` and `NAVIGATION-FOOTER-SPEC.md` for the complete site-level structure and styling rules.
