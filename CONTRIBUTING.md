# Contributing

1. Open an issue describing the reference, behavior, or accessibility problem.
2. Keep supplied screenshot evidence and mark assumptions as inferred/unknown.
3. Make the smallest coherent change and preserve existing routes.
4. Run `python tools/scripts/validate_project.py`, `node --check assets/landing/studio.js`, and `git diff --check`.
5. Include before/after screenshots for visual changes and note viewport dimensions.
6. Do not add unlicensed assets, credentials, or claims of Apple affiliation.
