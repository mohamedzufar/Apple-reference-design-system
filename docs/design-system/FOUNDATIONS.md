# Shared Foundations

## Grid
- Max content width: 1200px (wide editorial sections may reach 1280px).
- Desktop gutters: 40–64px; tablet: 28–36px; mobile: 20–24px.
- Use a 12-column grid on desktop; collapse to one column on narrow screens.
- Prefer asymmetrical editorial layouts only when they improve the content hierarchy.

## Spacing scale
`4, 8, 12, 16, 24, 32, 48, 64, 80, 96, 128px`

## Typography
Use SF Pro where licensed/available, with system sans-serif fallbacks. Large headings use tight line-height and slight negative tracking; body copy uses comfortable line-height.

## Radius
- Small controls: 12px
- Inputs / compact surfaces: 14px
- Cards: 20px
- Media: 24px
- Pills: 999px

## Interaction
- Button/control transitions: 160–220ms, ease-out.
- Use transform/opacity for motion where possible.
- Keep hover states subtle and provide clear focus-visible rings.
- Never rely on color alone to communicate selected, error, or success states.
- Respect `prefers-reduced-motion`.

## Accessibility checklist
- Semantic landmarks and headings in order.
- Visible keyboard focus.
- Contrast appropriate for text size and weight.
- Keyboard-operable controls.
- Touch targets approximately 44×44px where practical.
- Reduced-motion support.
- Form labels and useful error text.
