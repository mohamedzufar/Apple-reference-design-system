# v0.7 — Advanced Skill Upgrade

## Why this version exists
The earlier skill described visual cues but did not provide enough operational detail for implementation decisions, interaction contracts, or honest validation. This version adds an end-to-end reusable skill.

## Changes
- Added `docs/releases/APPLE-INSPIRED-INTERFACE-SKILL-V0.7.md`.
- Covers evidence vs inference, motion/scroll rules, drag interruption, glass materials, accessible component states, performance, reference traceability, and release gates.
- Changed `html` document scroll behavior to `auto` in both themes, so native scrolling remains the default and matches the prior v0.6 release notes.

## Validation boundary
This is a source/documentation upgrade and a consistency fix. It is not a claim of pixel-perfect Apple reproduction, browser certification, or measured FPS. Browser/device QA remains open.
