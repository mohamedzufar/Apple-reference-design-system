The repository root now opens a complete, polished landing page that explains the design system and provides direct access to the working product-storytelling demo. This makes the version difference visible immediately rather than hiding it in incremental documentation.

- Demo disclaimer and return navigation.

## Preserved
- Existing light and dark theme pages.
- Supplied reference corpus and prior skill/release notes.
- Existing v0.8 clone-studio demo and v0.9 optional tooling.

Static project validation and JavaScript syntax checks are run when packaging. They do not prove pixel-perfect visual similarity, browser FPS, screen-reader quality, or real-device performance. Browser testing remains a release step.

No Git remote push was performed as part of ZIP creation. Follow the root README to initialize or use an existing repository and push to a GitHub remote.
