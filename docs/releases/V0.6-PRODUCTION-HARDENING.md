# v0.6 Production Hardening Notes

## Included
- Preserved v0.5 pages, references, themes, and design documentation.
- Disabled global smooth document scrolling to avoid competing/laggy scroll behavior; native scrolling remains the default.
- Reduced persistent `will-change` promotion on reveal and explorer elements.
- Added reduced-transparency and increased-contrast preference styles, plus stronger reduced-motion fallback.
- Added safe glass-material fallback when backdrop-filter is unavailable.
- Hardened reveal initialization for browsers without IntersectionObserver and for runtime reduced-motion preference changes.
- Added this implementation note and a QA checklist.

## Important validation boundary
This release has source-level hardening and static checks only. It has not been certified by cross-browser visual testing, screen-reader testing, or real-device performance profiling. Do not describe it as independently QA-certified.

## Browser QA checklist
- [ ] Open every HTML page in current Chrome, Firefox, Safari, and Edge.
- [ ] Test fast wheel/trackpad scroll, touch momentum, anchor navigation, sticky header, and horizontal rails.
- [ ] Test 320px, 375px, 768px, 1024px, and wide desktop widths.
- [ ] Test keyboard-only navigation and visible focus.
- [ ] Test OS reduced-motion, increased-contrast, and reduced-transparency preferences where supported.
- [ ] Check console errors, missing assets, and broken local links.
- [ ] Record Lighthouse/Web Vitals on representative pages and compare against baseline.
