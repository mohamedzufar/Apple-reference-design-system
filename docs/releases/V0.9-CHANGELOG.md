## Existing content
The v0.8 site, assets, themes, and skill files are retained. Optional tooling does not modify existing pages by default.

## Validation caveat
The package can be structurally checked and scripts syntax-checked, but full browser tests require installing Playwright and serving the project locally. No browser-certified performance or visual-parity claim is made.
