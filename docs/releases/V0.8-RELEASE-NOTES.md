# v0.8 release notes — Product Storytelling & Motion Engineering

## Intent
v0.8 extends the v0.7 reusable skill with an explicit Apple product-page storytelling workflow and a stronger motion/accessibility/QA contract. The supplied screenshots informed pattern taxonomy and review criteria; they do not reveal Apple's internal implementation.

## Added
- Screenshot analysis template: observed / inferred / unknown, viewport and browser-zoom awareness.
- Story sequence: orient, reveal, explain, prove, explore, resolve.
- Section archetype guidance: cinematic hero, editorial split, feature grid, media rail, product explorer, comparison/specs, FAQ and footnotes.
- Motion guidance for interruption, pointer capture, scroll preservation, carousel boundaries and sticky-anchor overlap.
- Reduced-transparency and increased-contrast handling guidance.
- QA matrix across viewport sizes, input modes, preference settings and key interaction flows.
- Definition of done distinguishing static checks from real browser/device verification.

## Preserved
- Existing v0.7 pages, assets, tokens, light/dark theme structure, shared specs and screenshot corpus.
- No wholesale redesign of the demo pages and no new external dependencies.

## Validation scope
This release packages the updated skill and documentation with the existing project. Static checks can validate syntax and local references; they cannot certify FPS, real-device scroll smoothness, Safari behavior, screen-reader usability or pixel-level similarity. Run the included QA matrix before treating a deployment as production-ready.
